# Good Night Yoyo ❤️

مشروع رومانسي سينمائي من عبدالرحمن إلى آية.

## التشغيل

افتح `index.html` مباشرة في المتصفح.

## الموسيقى

ضع ملف الموسيقى الرومانسية باسم:

`assets/audio/romantic.mp3`

الموقع لا يعتمد على وجود الملف حتى يعمل.

## التقنيات

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Animations
- DOM Events
- Responsive Design

لا يوجد React أو Vue أو TypeScript أو Backend أو Database.
